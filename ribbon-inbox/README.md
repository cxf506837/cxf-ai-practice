# 拾光收集箱 · 核心源码快照

**[查看作品案例](https://cxf-portfolio.onrender.com/works/ribbon-inbox.html) · [合成资料界面](../site/public/landing-pages/portfolio-assets/ribbon-mobile.png) · [公开范围](NOTICE.md)**

为日常文字、链接和图片提供“保存 → 搜索/筛选 → 找回 → 整理 → 备份”的个人收藏流程。AI 功能由使用者主动触发；不自动读取整个收藏库，不自动抓取网页正文，也没有账号或云端收藏数据库。

## 这份源码能复现什么

这里公开 **1.1.0 本地工程的核心实现和离线 Node 测试**，包括 TypeScript 收藏业务、Web 开发网关与 Kotlin 原生适配。它不是完整安装包或可直接构建的完整 UI：第三方光带/开屏/按钮等素材的再分发许可记录不完整，暂未导出 UI 和资源，也未导出 Gradle 构建工程。不能用此目录单独构建 APK 或启动原版页面。

原本地工程和数据保持不动。这个边界比把演示截图误写成“全量源码已开源”更便于核对；公开源码不等于对第三方素材的许可授权。

## 主要流程与技术选择

| 模块 | 实现与边界 | 入口 |
| --- | --- | --- |
| 保存/检索 | 本地 IndexedDB 仓储；中文子串、英文大小写折叠、多词 AND；事务成功才提示保存 | [repository.ts](web/src/features/collection/repository.ts)、[search.ts](web/src/features/collection/search.ts) |
| 备份 | JSON 校验、预览后整批合并，冲突保留副本；v2 保留图片，v1 不静默丢图 | [backup.ts](web/src/features/collection/backup.ts) |
| 图片与问答 | 单图最多 4 MiB；问答主动选 1–5 条资料，限制问题和上下文；校验来源 ID，结果仍需人核对 | [images.ts](web/src/features/collection/images.ts)、[cloud.ts](web/src/features/collection/cloud.ts) |
| Web AI 网关 | 服务端保管凭证；超时、输入/输出校验、并发限制和脱敏错误；离线测试注入 mock | [ai-gateway.cjs](server/ai-gateway.cjs) |
| Android | Kotlin WebView 原生通道、分享队列、系统文件导入导出；AndroidKeyStore 加密模型凭证，直连官方服务 | [原生源码目录](android/app/src/main/java/com/ribboninbox/app/) |

原完整 UI 技术为 Next.js 16.4.0、React 19.3.0、TypeScript、Tailwind 4；Android minSdk 26、compile/targetSdk 36。这些是原工程版本，不意味着此核心快照包含完整前端/安卓构建依赖。

未配置模型时，原应用的本地收藏仍可使用。OCR 先展示预览，再由使用者决定是否追加正文；资料问答只发送勾选的文字内容，不自动发送图片或抓取链接。Web 与 Android 的收藏各自保存，通过备份迁移，不自动同步。

## 本地复现离线测试

需要 Node 24.19.0 或更高的兼容版本、pnpm 11.25.0，在本目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm test
```

只安装 TypeScript 5.9.3 用于加载原 TypeScript 模块；测试使用 Node 内置 test runner。`tests/modules.cjs` 已将原机器绝对依赖路径改为本目录依赖，其余导出源码保持原字节。模型请求由合成 mock 注入；测试会在本机回环地址启动临时 HTTP 服务，不连接供应商，不需要真实密钥。

测试覆盖非法输入、搜索排序/分页、备份版本与图片字节、问题长度和来源校验，以及网关鉴权、格式/超时/取消等已有用例。本次实际通过数量与环境记录在[2026-10-23 验证说明](../docs/README-UPDATE-20261023.md)。测试成功不能证明 UI、IndexedDB 真实事务、Android 运行或真实模型语义均已验收。

## 一次失败与限制

原工程故障注入发现：草稿写入失败后退出编辑可能丢失当前输入。后来改为保留输入，待重试成功再退出，并检查刷新恢复。这说明“保存按钮点过了”不足以证明可靠保存，需要事务和故障路径验证。

当前仍待真机核对：模型密钥保存、移动网络、系统选图、两个真实来源应用分享、覆盖安装保留数据和性能。历史模拟器性能观测未达原定目标，不能用构建或桌面截图代替。此快照未附原机器的浏览器/模拟器驱动和运行证据文件，不假装这些历史检查已经在新机器复现。
