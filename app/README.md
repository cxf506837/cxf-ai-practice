## 解决的问题与实现

群通知经常混有闲聊、模糊截止时间和后续更正。此应用把“粘贴 → 预览发送内容 → 真实模型提取 → 原文核对 → 人工修改确认 → 保存/完成/更正”串成闭环；模型不自动执行任务。

React + TypeScript 展示候选与任务，Node HTTP 服务校验请求/模型输出，SQLite 保存原文、出处和待办；DeepSeek `deepseek-flash` 负责候选提取。模型凭证留在服务端。`APP_MODE=demo` 是独立的固定合成样例、临时会话和持久预算路径，不能把 local 模式直接暴露公网。

## 启动

需要Node.js 24.19.x与pnpm（本机验证版本为24.19.0、11.25.0）。依赖版本由现有锁文件固定。首次在本目录运行：

```powershell
pnpm install --frozen-lockfile
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

如果已有.env，保留现有文件。用本地编辑器在.env设置`DEEPSEEK_API_KEY`，不要把真实密钥粘贴到聊天、终端命令或Git。应用固定使用官方DeepSeek API的`deepseek-flash`，关闭thinking；`PORT`默认4317。

密钥留空时仍可启动页面、管理来源和本地已有待办；页面提示未配置并禁用发送预览，服务端拒绝新分析且保留输入，不会生成替代结果。空密钥复验还需清除启动进程继承的同名环境变量。已从源码快照在新目录验证启动、空数据、来源持久化及空密钥拒绝路径，详见[交付复验](docs/DELIVERY.md#从新目录运行)；它不代替真实模型验收。

```powershell
pnpm build
pnpm start
```

打开[本地页面](http://127.0.0.1:4317)。服务仅绑定127.0.0.1，浏览器与API使用同一端口。端口占用会报错，请调整.env的PORT后重启，不需要停止其他项目。停止服务使用Ctrl+C。

## 使用

1. 新建或选择来源，粘贴合成或脱敏消息；可填写消息日期背景和自己的角色。
2. 点击“预览将发送的内容”，核对内容后点击“确认发送并分析”。当前消息、日期背景和角色会发送给DeepSeek，来源名称和历史任务不会附加发送。
3. 对照出处，修改标题、对象、日期、材料和疑点，然后点击“确认并保存待办”。不相关的候选可以忽略；没有任务也可能是正常结果。
4. 已保存待办支持完成/重新打开、编辑与取消。删除需再次确认，仅删除所选待办，原消息和分析记录保留；刷新后仍可查看当前任务。
5. 新通知是旧任务的更正时，在候选中主动选择同来源旧任务，对照旧字段/原文和新字段/原文，再点击“确认更正此任务”。更正保留完成状态与初始出处，并追加更正出处；已关联候选不会再另存重复任务。不自动匹配相似通知，撤销也需人工处理。
6. 点击“下载当前数据 JSON”下载本机当前来源、原消息、候选、任务与更正出处。文件含原消息，请妥善保管；不含密钥或环境配置。当前不支持导入恢复，导出不等于一键恢复。

多页面同时修改同一任务时，旧版本会被拒绝，编辑草稿保留。点击“重新读取当前数据”查看最新任务，再明确放弃旧编辑草稿/按最新版本重新核对后操作，避免覆盖其他页面的修改。删除任务后，原候选只有再次明确确认才会重新保存。

消息上限12,000字，单次分析最长45秒，输出最多20条候选、4,096输出tokens。单条分析只请求模型一次，没有自动重试或备用假结果；失败保留输入，由用户明确重试。当前没有用户取消入口，关闭页面不保证立即停止请求或费用；服务端仍以45秒作为请求时间上限。

同来源、完全相同文本、日期及角色复用已有分析；不同来源隔离，同候选重复确认只保存一项。每条新分析记录提取配置指纹。更新配置后，旧配置的空结果允许重新分析，同时保留旧记录；同配置空结果继续复用。历史非空候选和已确认任务始终复用，不自动升级全部历史候选，避免跨版本生成重复任务。

## 数据与限制

SQLite位于被忽略的`data/tasks.sqlite`；密钥位于被忽略的`.env`。不将这些文件加入Git或公开演示。保存数据与源码版本分开，源码回滚不会自动恢复或删除数据库。迁移机器时需自行备份data目录，复制真实数据前先确认用途与隐私。

出处校验仅保证引用可在原文定位，不能证明模型语义正确。模糊日期会保留原文和待确认状态，最终由人核对。更正关联只在本地操作，不额外调用模型或发送旧历史。不会自动监听群聊、接管手机、发消息或执行任务。

本机删除与供应商端数据保留不是同一回事；开发和演示仅用合成消息。私人内容发送前需用户核对供应商数据条件。新增Demo的真实Redis与云HTTPS验收已通过，公众窗口曾一次激活，现已结束；不得将local模式直接暴露到公网。
