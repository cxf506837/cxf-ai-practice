## 展示顺序

1. 选择合成来源和历史通知记录，查看已经缓存的候选。
2. 人工编辑标题、确认保存、展开原文、完成任务。
3. 选择同来源的历史更正记录，查看候选，主动关联旧任务，核对新旧原文后应用更正，保留完成状态。
4. 刷新并核对任务与初始/更正出处，实际下载当前合成数据 JSON。
